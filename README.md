# alcarcia-website

Al igual que con [damalga](https://github.com/damalga/damalga-web), este proyecto arrancó con el fin entender las bases de [React](https://es.react.dev) y ya que tal dar a conocer mis pinitos como productor de música electrónica.

Además de dar a ver mis capacidades como maquetador web y "estratega" del diseño y desarrollo responsive. Luego comencé a dominar el DOM haciendo uso de [jQuery](https://jquery.com), hasta que me di cuenta de que todo de lo que era capaz de hacer con esta libreria en realidad era capaz de hacerlo sin ella.

Siempre he sido muy de trabajar en "modo por defecto" y con el menor número de dependencias posibles.

Sin embargo, tanto [Angular](https://angular.dev), como React, como [Vue](https://vuejs.org) parten de juntar un montón de dependencias Javascript (Js)... Amo Js, pero no puedo ningunear la brutal capa de abstracción que maneja el lenguaje ni lo mucho que me abruma esta sensación de falta de control.

Creo que para lidiar con esta frustración compré un Thinkpad al que poner una distribución GNU/LInux con el que aislarme y comenzar una nueva andadura con Bash, el scripting y bueno... el Hacking en general.

No abandono Js, no abandono la música; simplemente no abandono... Disfruto del camino, no existe el destino.

;) un abrazo.. virtual!
